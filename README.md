# Mirabel Hollow’s Apothecary Journal

The public journal is published from `main` → `/docs` using GitHub Pages.

Add a Markdown file to `docs/data/entries/` to publish a new entry. Use a name like
`Y1 Summer Week 01.md` for chronological sorting. Existing Obsidian-style links
such as `[[Felux Dawncrest]]` link to profiles and generate journal appearances.

For a patient visit, put `Patient: [[Name]]` directly above `Ailment: [[Ailment]]`.
Use a `### Potion` section for a brew name, `[item:: [[Ingredient]]]` lines, and
`[outcome:: Cured]` if applicable. Each patient starts a fresh visit. Profiles
in `docs/data/characters/`, `familiars/`, and `places/` match links by filename.
